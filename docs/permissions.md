# 权限矩阵：三种内置用户组

权限以字符串标识，后端在路由层校验，前端据此过滤管理页标签页与按钮。

| 权限 | 说明 | admin | editor | user |
| --- | --- | :--: | :--: | :--: |
| （基础）浏览目录 / 阅读 / 检索 | 所有登录用户 | ✔ | ✔ | ✔ |
| （基础）书签、阅读进度、黑名单、提交建议修正 | 仅影响本人视图 | ✔ | ✔ | ✔ |
| `thread.download` | 提交下载申请、查看全部下载任务、取消/重试 | ✔ | ✔ | ✔ |
| `thread.edit` | 修改串信息与标签、删除串 | ✔ | ✔ | ✘ |
| `user.manage` | 用户列表、新建/停用/启用/删除用户、邀请码 | ✔ | ✘ | ✘ |
| `db.manage` | 备份 / 恢复 / 清理 | ✔ | ✘ | ✘ |
| `log.view` | 查看系统日志 | ✔ | ✔ | ✘ |

定义在 `backend/app/services/auth.py` 的 `GROUP_PERMISSIONS`。

## 页面可见性

| 页面 | 路径 | 进入条件 |
| --- | --- | --- |
| 登录页 | `/login` | 未登录 |
| 目录页 | `/home` | 已登录 |
| 阅读页 | `/t/:threadId` | 已登录 |
| 管理页 | `/admin` | 已登录且至少拥有一个管理权限；无权限时提示「没有可用的管理功能」 |
| 设置页 | `/settings` | 已登录 |

## 下载任务

任何登录用户都能提交下载申请，也能看到所有人的任务状态，并且可以取消/重试任意任务。
若要收紧成「仅提交者本人或 `thread.edit` 可取消」，只需在
`queue.cancel_task` / `queue.retry_task` 上追加判断，前端按钮已按任务字段渲染，无需改结构。

## 账号被锁时怎么办

登录连续失败 `login_fail_limit` 次（默认 5）会临时封禁 `login_ban_seconds`（默认 86400 秒 = 1 天）；
管理员在管理页手动「停用」则是**永久**停到手动启用为止（`banned_until = DISABLED_UNTIL`）。
两种情况都会把该账号已登录的会话立刻作废。

如果被封的正是唯一的管理员，前端谁也进不去，只能从服务器解：

```bash
make users ARGS="--unban admin"     # 或在容器里 python scripts/manage_users.py --unban admin
```
